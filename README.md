# Coworker

Build a web app called [AppName], a professional reputation platform similar to Yelp but for professionals. Users have profiles showing name, headline, company, and photo. Other users can leave a 1-5 star rating and a short written review (max 250 characters) on a professional's profile. Use Supabase for auth and database. Design should feel clean, trustworthy and professional, with a blue/neutral palette, similar to LinkedIn. Start with the landing page, sign up/login and a basic navigation bar. Do not build other features yet.
